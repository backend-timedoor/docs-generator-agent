---
description: Initialize this doc-agent for a project (creates docs/project-context.md)
argument-hint: "[optional notes to seed the file]"
allowed-tools: Bash, Write
---

Create `docs/project-context.md` if it doesn't already exist.

- If it exists: leave it untouched, tell the user it's already set up.
- If it doesn't exist: create `docs/` if needed, then write `docs/project-context.md` with this template:

```markdown
# Project Context

Manually maintained. Read by docs-orchestrator as background context (Phase 0),
never overwritten or regenerated by the pipeline.

## Overview

<!-- What this project is, who it's for -->

## Key domains / modules

<!-- Core business domains worth prioritizing in docs -->

## Notes for doc generation

<!-- Versioning quirks, known risk areas, anything the analyzers can't infer from code -->
```

If $ARGUMENTS is non-empty, fold it into the relevant section instead of leaving that section as a placeholder comment.

Report the file path created, or that it already existed.
